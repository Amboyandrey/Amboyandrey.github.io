# Amboyandrey.github.io

Portfolio of Niño Andrey Amboy — Software Engineer.

Plain HTML, CSS, and JavaScript. No build step: GitHub Pages serves `index.html` directly.

```
index.html     the page
css/style.css  design tokens (light/dark), layout, components
js/main.js     theme toggle, streaming hero demo, system-map tooltips, scroll reveal
```

Preview locally with any static server, e.g. `python3 -m http.server 8000`.
