ReCore

Multi-workspace chat platform that talks to any LLM, on keys each workspace brings itself.

Source ↗

What it does

  • Bring your own key — Anthropic, OpenAI, Google, or any OpenAI-compatible endpoint, per workspace. Keys are envelope-encrypted and validated live before they're stored.
  • Streaming that survives — SSE over a Redis stream, so a refreshed tab picks the reply back up mid-answer. Stop works across processes; a retried send attaches to the in-flight generation instead of billing twice.
  • Tools the model can call — web search plus any HTTP endpoint a workspace registers, run in a bounded agent loop (timeout, result cap, iteration ceiling).
  • Assistants that delegate — one assistant hands a task to another as an ask_<name> tool; the delegate runs its own model, memory, and tools.
  • Memory, knowledge, workflows — mem0-backed recall, pgvector RAG with cited sources, and background multi-step chains replayable from a run history.

ReScope

Multi-tenant CRM that profiles a company from its own website — with evidence for every claim.

Source ↗

What it does

  • Tiered profiling — a no-LLM discovery pass (robots, sitemap, links) feeds text extraction; sites hiding content behind tabs or infinite scroll escalate to a visual browser agent that clicks like a person and screenshots evidence.
  • Evidence, not claims — every product, service, and competency links to the exact page and quote it came from.
  • Semantic everything — search accounts, find similar companies, and chat grounded only in what retrieval found, on a self-hosted embedding model (no per-search API cost).
  • Isolated three ways — tenant resolved from the Host header only, composite foreign keys make cross-tenant references impossible, and row-level security backstops both.
  • Plans & quotas — platform-paid by default with per-plan ceilings; a workspace can bring its own keys for six providers and opt out of quotas.
